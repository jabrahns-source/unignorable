# Unignorable — The Receipt Stack

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**Elite AI-powered system for technically strong founders to generate enterprise outreach, content, and proposals that land — even when facing structural barriers.**

Built while homeless on a Chromebook. Zero gatekeepers.

## Status

Scaffold / strategic surface. Core receipt and deterministic compliance logic lives in the Kerna-Ledger / Q-Reg / VERA family:

- [Q-Reg](https://github.com/jabrahns-source/Q-Reg)
- [vera-enterprise-engine](https://github.com/jabrahns-source/vera-enterprise-engine)
- [GridPulse](https://github.com/jabrahns-source/GridPulse)

This repository is reserved for the outreach / content / proposal generation layer that consumes verifiable receipts as proof-of-work artifacts.

## Design principles

- Receipt-first: every claim is backed by a verifiable artifact
- Deterministic where possible
- Zero-budget runnable
- No gatekeeping of the verification surface
